# Data availability

Distributed here: numeric evaluation CSV/JSON files, scripts, configurations, documentation and provenance hashes.

Retained separately in the author's local `olmocr_vlm` experiment copy: source scans, manual references, generated predictions, adapters, optimizer states, original logs and the 2026-09-28 audit archive. No external access service or promise to supply these files is established by this statement.

The complete 98-page corpus is not in this repository. Full inference/training reproduction is not possible from this repository alone. Metric consistency and file integrity can be inspected without the omitted data. Complete metric recomputation requires the separately retained reference/prediction files.

For a future Zenodo deposit, use the title in DATASET_CARD.md for this numerical evaluation package. If the scope is expanded, update the data card, rights statement, citation metadata and file inventory together.
